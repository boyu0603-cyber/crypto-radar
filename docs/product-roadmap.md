# Product Roadmap

## Stage 0: Public-Safe Portfolio Documentation

Current stage.

Goals:

- Explain the concept safely
- Document architecture and workflow
- Define responsible AI boundaries
- Create a synthetic radar item example
- Avoid private or sensitive trading information

## Stage 1: Source Category Taxonomy

Goals:

- Define public source categories
- Separate primary and secondary sources
- Identify public-safe source metadata
- Create source provenance rules

## Stage 2: Event Classification and Review Item Template

Goals:

- Define event categories
- Create a structured review item template
- Add uncertainty and missing-information fields
- Test synthetic examples against the evaluation rubric

## Stage 3: Human Review Workflow and Alert Design

Goals:

- Design review states
- Create alert templates
- Define human override and dismissal logic
- Keep all outputs as review items, not trading instructions

## Stage 4: Public-Safe Screenshots and Synthetic Examples

Goals:

- Create synthetic dashboard data
- Build public-safe radar screenshots
- Add sample alert screenshots
- Prepare a short demo walkthrough
- Avoid real signals, accounts, holdings, or private sources

## Stage 5: Enterprise Intelligence Workflow Adaptation

Goals:

- Adapt the workflow for enterprise intelligence monitoring
- Explore policy, competitor, market, or risk intelligence use cases
- Add governance and review roles
- Connect the concept to broader information-to-decision systems

## Roadmap Principle

The roadmap is intentionally staged. Crypto Radar should be presented as a market intelligence workflow and early enterprise intelligence concept, not as a deployed trading system.
