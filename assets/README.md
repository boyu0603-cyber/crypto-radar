# Assets

This folder is reserved for future public-safe visual assets.

Allowed future assets:

- Synthetic radar dashboard mockup
- Workflow diagram
- Sample alert screenshot
- Public-safe demo walkthrough

Disallowed assets:

- Real trading signals
- Account data
- API keys/tokens
- Private data feeds
- Portfolio holdings
- Proprietary strategies
- Customer records
- Private Telegram configuration
- Production deployment details

Any future asset should be reviewed before publication to confirm that it contains only public-safe material and does not provide financial advice.
